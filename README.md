## Projetos

### ✊✋✌️ Jokenpô em Python
Implementação do jogo Pedra, Papel e Tesoura em Python, com interação via terminal, animações em ASCII e três modalidades de jogo: Jogador vs Jogador, Jogador vs Computador e Computador vs Computador. Trabalho da faculdade.
📁 [`/Jokenpo_GGP`](https://github.com/guimmuniz/portfolio_apple_academy/tree/main/Jokenpo_GGP)

### 🚢 Batalha Naval em Python
Jogo de Batalha Naval desenvolvido em equipe (com Gustavo Kenzo Sato Hamada e Pedro Joaquim Freire de Lima), aplicando matrizes, estruturas condicionais e de repetição, validação de entradas e modularização do código. Utiliza a biblioteca Pygame para efeitos sonoros e trilha sonora. Trabalho da faculdade.
📁 [`/PjBL-Batalha-Naval`](https://github.com/guimmuniz/portfolio_apple_academy/tree/main/PjBL-Batalha-Naval)

### 💰 Finance — Aplicação Web (destaque do CS50)
Aplicação web desenvolvida em Flask como projeto final do curso CS50 (Harvard), simulando compra e venda de ações. Inclui autenticação de usuários, integração com API de cotações e banco de dados com SQLite.
📁 [`/finance`](https://github.com/guimmuniz/portfolio_apple_academy/tree/main/finance)

### 📚 CS50's — Introduction to Computer Science
Repositório com minhas soluções para os problemas do CS50x (Harvard), curso concluído, cobrindo C, Python, SQL, Flask, HTML, CSS, JavaScript e Bootstrap. Organizado por tema (C, Python, SQL e Web).

### 🌧️ Varal Inteligente (TCC)
Sistema automatizado que detecta chuva por sensores e recolhe roupas de forma autônoma. Projeto de conclusão do curso técnico em Mecatrônica, desenvolvido do zero: programação embarcada em C, esquema elétrico e estrutura mecânica. Apresentado na FECIVALE (Feira de Ciências do Vale do Ribeira) e em banca avaliadora.

### 📊 Consultoria IF Mais Empreendedor
Projeto de consultoria empresarial para uma pequena empresa do Vale do Ribeira, com foco em análise de processos e dados para aumento de produtividade.
